# 3科目の最初の単元

更新: 2026-10-07。個人用の小さな学習範囲として、3科目各1単元を用意する。Notionの教材を読み取り、実際の学習範囲と照合した内容をGitで保存する。Notionへの書き戻し、DB migration、資格情報の変更は行わない。

## 利用場面と到達点

`/units` から科目を選び、単元の概要で目標・問題数・出典を確認して「単元を練習する」を押す。短答は回答を照合し、説明は自分の言葉で書いて、見本と評価観点を読んで自己評価する。評価した回答を保存し、終了時に正答率・要再確認の数・各問の評価と保存状況を見る。

| 科目・単元 | 内容 | 問題数・目安 | 終了後にできること |
| --- | --- | --- | --- |
| くずし字「あ・い・うを字形から読む」 | 第1回の3文字を、実資料の字形各2例で読む。2例目は順番を変える | 短答6問、5〜10分 | 読みが同じでも形が違うことを体験し、結果に残る字形と読みを見直せる |
| 西洋美術史「先史美術：作品と背景を結ぶ」 | 旧石器時代、誇張、抽象化、ラスコーとアルタミラの国、ヴィレンドルフ像の素材、形と用途の区別 | 短答6問＋説明1問、5〜10分 | 作品を時代・場所・素材・表現と関連付け、観察事実と意味の解釈を区別できる |
| 西洋哲学史「アルケー：答えと説明をつなぐ」 | タレスの水、アペイロン、アナクシメネスの空気を短答。共通原理の問い、水とアペイロンの違い、希薄化と凝縮を説明 | 短答3問＋説明3問、10〜15分 | 用語を覚えるだけでなく、根源の考え方と変化の説明を自分の言葉で述べられる |

所要時間は初回利用の仮の目安。実際の利用時間はまだ測定していない。美術史は美術検定の基礎知識と情報の関連付けを参考にした独自教材であり、特定級の全範囲や公式過去問を提供するものではない。現段階は文字による知識問題で、作品画像を見て識別する問題は今後追加する。

## 説明の評価

説明4問は、見本、必要な要点、許容する言い換え、重大な誤解を保存版の教材に持つ。自由な1〜3文の入力を受け付け、「もう一度・難しい・できた・即答」の観点も説明用に変える。

`rubric-self-evaluation-v1` は自動正誤判定を行わず、`gradingStatus=ungraded`、`isCorrect=null` を返す。見本と同じ文章、別の表現、誤った説明のいずれもサーバーが正答・誤答と確定しない。保存するものは回答原文と利用者の自己評価。短答の正答率に説明問題を混ぜない。自動意味評価の導入には別途、評価例と誤判定率の検証が必要。

## 保存・再開と復習予定

- 単元はすべて追加の練習として発行する。回答履歴はSupabaseへ保存するが、既存の復習期限・反復回数・復習機会は変更しない。「今日の復習」は従来の予定に沿って別に進める。
- 一覧・概要の表示だけでは問題を発行しない。明示的な開始POSTで現在のNotion範囲と出題設定を再確認し、保存した問題版からカードを作る。
- 開始した問題の組は、回答前にこのブラウザのIndexedDBへ保存する。自己評価を選び、既存の回答outboxへの保存が完了した問題を「回答済み」として再開する。
- 送信前の通信失敗、サーバー保存後の応答消失でも、同じ回答IDで再送・受領結果の照合を行う。別の新しい回答を重ねて保存しない。
- 同じ端末・同じブラウザ・同じアプリのURLから、概要の「途中から再開」で続ける。完了後は「前回の結果を見る」で表示だけを再開できる。未完了・未同期の組を新しい練習で上書きしない。
- 入力中、または「回答する」の後で自己評価をまだ選んでいない文章は再開位置の対象外。ブラウザの保存領域を消した場合や、別の端末への引継ぎには対応していない。
- 現在の結果画面はこのブラウザの直近の単元。過去の回答はSupabaseに残るが、3科目共通の履歴画面と過去の説明原文の閲覧は次の作業で用意する。

保存済みの単元回答・問題の保存版は既存の16テーブルのバックアップ対象に含まれる。単元の端末内の組、未同期回答、入力中の文章は含まれない。詳細は [学習バックアップ](LEARNING_BACKUP.md)。通信なしでアプリを起動する実機検証は、既存のオフラインpilotと別に残る。

## 教材の根拠と画像の利用条件

2026-10-07に実Notionの第1回講義と知識を読み取り、19問すべてのScope subjectが現在の学習範囲に入ることを確認した。Scopeは将来変わり得るため、開始時と初回回答受理時にも読み取る。

- くずし字: 第1回 `3ccd2793-4134-8181-9baf-f81888996b38`、文字「あ・い・う」の3ページ。今回の字形は読みだけを扱い、字母を判定しない。既存「あ」pilotの問題版は変更しない。
- 美術史: 第1回 `3bdd2793-4134-8105-8e0f-c17980f50ec8`、ラスコー・アルタミラ・ヴィレンドルフ像など。既存3問をそのまま利用し、国・素材・解釈の4問を追加。[美術検定の公式出題範囲](https://www.bijutsukentei.com/coverage)を教材構成の参考とした。
- 哲学史: 第1回 `3bdd2793-4134-8105-904b-d47a4f0f6f52`、タレス・アペイロン・アナクシメネスなど。既存3問はhashを変えずに利用し、説明3問を追加。

字形6画像は [CODH「日本古典籍くずし字データセット」](https://codh.rois.ac.jp/char-shape/book/200015843/)の『日本永代蔵』から公式IIIFの切り出し画像を取得した。国文研ほか所蔵／CODH加工、DOI `10.20676/00000340`、**CC BY-SA 4.0**。元画像・座標・寸法・読みのラベル・SHA-256は `src/lib/review/units/glyph-assets.ts` に記録し、取得後のJPEGの内容は加工していない。画像の表示と結果画面に出典・利用条件を表示する。この画像のライセンスはアプリのソース全体へ適用する指定ではない。

## 実装と検証

| 責務 | ファイル |
| --- | --- |
| ブラウザへ渡す概要・単元の順序 | `src/lib/review/units/catalog.ts` |
| 問題の保存版・説明の評価観点 | `src/lib/review/units/registry.ts` |
| 発行済み内容の照合・カード化 | `src/lib/review/units/core.ts` |
| Scope、追加練習の発行、既存の回答保存への接続 | `src/lib/review/units/runtime.ts`、`app/api/units/start/route.ts` |
| この端末の問題の組と回答済み位置 | `src/lib/review/units/run-store.ts`、`progress.ts`、`StudyUnitPractice.tsx` |
| 説明の入力・評価観点・結果 | `ExplanationRubricPanel.tsx`、既存 `ReviewSession.tsx` |

既存の日々の出題registryとimmutable hashは保持する。単元固有の問題を通常の復習候補へ自動追加しない。3科目の既存出題設定とglobal Objective v2設定が有効なときに新しく開始できる。停止中でも、すでに保存した組の再開と既存回答の同期を妨げない。

検証の完了条件は、3科目それぞれ390px/820pxで全問回答し、原文・評価・保存結果が一致すること。説明を完全一致判定しないこと。既存の未来の復習予定が単元終了前後で一致すること。送信前失敗と受理後消失から再起動し、4問目から再開して、二重保存・SRS更新がないこと。一覧・概要・結果の再表示が新しい問題を発行しないこと。実行方法と37ケースの内訳は [ブラウザ検証](BROWSER_E2E.md)。実行結果と本番のSHAは開発記録に分けて記録する。

## 次の段階

3科目共通で、日付・単元・回答原文・短答の採点または説明の自己評価・保存状況・次回予定を読める履歴を用意する。追加練習と復習予定を同じ指標に混ぜない。教材追加は既存のScope・保存版・画像manifestを活用し、最初の利用から再確認したい点を確認してから広げる。
