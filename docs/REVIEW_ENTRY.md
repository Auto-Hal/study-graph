# 3科目の今日・復習入口

更新: 2026-10-07。

## 利用者に見える内容

「今日」と「復習」は、くずし字・西洋美術史・西洋哲学史を同じ構成で表示する。科目の優先順位は設けず、利用者が選ぶ。

- **復習**: 学習済みで期限に達した、現在の学習範囲にある問題。
- **未学習**: まだ回答・評価していない、現在の学習範囲にある問題。Notionの講義や文字そのものが未学習という意味ではない。
- **次回の復習**: 現在の範囲で最も近い将来の期限。日本時間で表示する。
- **取得不可**: 教材の範囲や保存済み予定を読めない。0問・全問未学習と断定しない。
- **準備中**: 出題停止設定で新しい出題が無効。問題がなくなった状態と区別する。
- **練習**: 旧方式で保存先を読めない場合の既存の練習。保存を保証する問題数として扱わない。

問題数は1回のセッションで選べる数。くずし字は現在の1問pilot、哲学史と美術史は既存の上限12問。Objectiveの教材順、続いて旧方式の期限順・未学習順を維持する。既存の表示用候補一覧の長さを復習数にしない。

開始までの間に別の端末で回答したり教材が変わったりした場合は、セッションで確認した内容が優先される。入口の観測だけで問題の発行や保存の成功を保証しない。

## 読み取りと実際の出題

`availability.ts` は読み取り専用。`candidates.ts` をセッションと共有し、教材の対象範囲と選択肢の品質条件を合わせる。Objectiveの予定は `(project_id, objective_id, srs_epoch)` で照合し、旧方式の `item_id` の予定から推測しない。将来の予定・他科目・別世代の予定を混同しない。

通常の教材画面は検証済みsnapshotの表示を維持する。一方、既存の美術史・哲学史snapshotには、出題が使う講義日付・完了状態・直接Relationの全根拠がない。そのため、この**出題予定パネルだけ**はReviewと同じNotionの読み取り元から最新の範囲を確認する。古いsnapshotから出題可能と断定する変更はしない。科目ごとのSuspense境界で先に画面を表示し、DBの共通読取は1リクエスト内でまとめる。Notionの遅さ・利用制限は依然影響し、読めない場合は取得不可を表示する。将来は範囲の根拠を含むsnapshotへの整理を検討する。

入口はarchiveの登録、instance発行、回答・SRS更新、snapshot更新を行わない。出題リンクのprefetchも無効。実際のセッションは従来どおり新しい範囲を確認し、DBのロック下で期限・世代・再利用を決める。教材のsnapshot更新は各workspaceで既存の仕組みを使う。

## DB追加と反映順

`20261007112918_review_schedule_read.sql` は既存22 migrationへの追加。読み取り関数 `study_graph_objective_review_schedule(uuid)` だけを作る。既存の回答・予定を更新せず、旧関数・writer・offline契約を変更しない。

privateテーブルへの直接SELECTは引き続き禁止。固定search_pathのSECURITY DEFINER関数にし、PUBLIC/anon/authenticatedのEXECUTEを剥がし、service_roleだけに許可する。アプリがサーバーに保持するlearner IDで絞る。サービス資格情報をブラウザに送らない。既存のlearner方式に合わせた境界であり、新しい利用者管理は導入しない。

反映は、隔離検証 → GitHub CI → 読み取り関数の追加 → 本番コード。DBが先行しても旧コードに影響しない。関数未適用・読取失敗では取得不可になり、予定を作り直すことはない。ロールバックは以前のコードへ戻し、読み取り関数は残してよい。出題停止設定はこの変更で有効化しない。

## 確認結果と残る範囲

- unit/contract 593件（524 + 17 + 52）、型検査成功。
- 実PostgreSQL 5組成功。追加RPCの権限、科目・learner・世代の分離、read-only transaction、読み取り前後の学習データ一致を確認。
- ブラウザ24ケース成功。従来の15保存・復旧ケースに、入口390px/820px、Scope/DB読取失敗、3科目の将来期限→期限到来→実出題、科目flag停止/global v2停止を追加。
- 隔離ソースコピーで `next build --webpack` 成功。GitHub CIの通常buildも反映前に確認する。
- 390px/820pxの入口の画像を目視確認。実機Safari、オフライン起動、全Objective教材、美術検定の問題追加、説明の意味評価は今回の検証範囲外。

教材はまだ各科目5〜10問の実用範囲に達していない。入口改善の完了をアプリ全体の完成とは扱わない。次は最小のバックアップ・復元手順と、3科目の教材・共通履歴を進める。
